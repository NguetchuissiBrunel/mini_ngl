# Mini NGL 💘

Une application web interactive et élégante pour envoyer des messages anonymes pour la Saint-Valentin.

## Fonctionnalités 🌹

-   **Message Anonyme** : Envoyez et consultez des messages en toute simplicité.
-   **Thème Dark Rose** : Une interface immersive aux tons sombres et élégants.
-   **Animations** : Cœurs flottants et effets interactifs pour une expérience fluide.
-   **Design Responsive** : Optimisé pour tous les écrans, du mobile au desktop.

## Technologies Utilisées ✨

-   **Next.js 15+** (App Router & Server Components)
-   **TypeScript** (Typage statique robuste)
-   **Firebase** (Backend & Base de données)
-   **Framer Motion** (Animations fluides)
-   **Tailwind CSS** (Stylisation)
-   **Lucide React** (Icônes)
-   **Canvas Confetti** (Effets festifs)

## Installation Locale 🚀

1.  Cloner le projet :
    ```bash
    git clone https://github.com/votre-username/mini_ngl.git
    cd mini_ngl
    ```

2.  Installer les dépendances :
    ```bash
    npm install
    ```

3.  Configurer l'environnement :
    Créez un fichier `.env.local` à la racine et ajoutez vos clés Firebase.

4.  Lancer le serveur de développement :
    ```bash
    npm run dev
    ```

## Déploiement 🌍

L'application est optimisée pour un déploiement sur **Vercel**.
